# Smart Attendance System

A robust and efficient web-based attendance management system designed for educational institutions. This system streamlines the attendance process using QR code scanning, manual entry for teachers, and device locking for security.

## 🚀 Features

### For Students
-   **QR Code Attendance**: Scan a dynamic QR code generated by the teacher to mark attendance instantly.
-   **Device Lock Security**: Accounts are locked to a single device (phone/laptop) to prevent "buddy punching" or proxy attendance.
-   **Dashboard**: View attendance percentage per subject and detailed history.
-   **Join Classes**: Easily join classes using a unique Class ID created by teacher.

### For Teachers
-   **Dynamic QR Generation**: Generate time-limited QR codes (valid for 15 seconds) for secure attendance marking.
-   **Manual Attendance**: Manually mark or correct attendance for specific dates.
-   **Class Management**: Create classes, add subjects, and manage student enrollments.
-   **Reports & Exports**: View detailed attendance reports and export data to CSV for offline records.
-   **Device Reset**: Admin capability to reset a student's device lock in case of lost or changed devices.

## 🛠️ Tech Stack

-   **Frontend**: EJS (Embedded JavaScript templates), CSS, Vanilla JavaScript
-   **Backend**: Node.js, Express.js
-   **Database**: MongoDB (Mongoose ODM)
-   **Authentication**: Express-Session, Bcryptjs
-   **Utilities**: `qrcode` (for generating QR codes)

## 📦 Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Surajmishra17/SIH-smart-attendance-.git
    cd SIH-smart-attendance-
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Environment Setup**
    Create a `.env` file in the root directory and add the following:
    ```env
    PORT=3000
    MONGODB_URI=your_mongodb_connection_string
    SESSION_SECRET=your_secret_key
    ```

4.  **Run the application**
    ```bash
    npm run dev
    ```
    The server will start at `http://localhost:3000`.

## 📖 Usage

1.  **Register/Login**: Users can sign up as either a 'Student' or 'Teacher'.
2.  **Teacher Workflow**:
    -   Create a Class.
    -   Add Subjects to the Class.
    -   Select a Subject and click "Generate QR" to start a session.
    -   Share the Class ID with students.
3.  **Student Workflow**:
    -   Enter the Class ID to join.
    -   Go to the dashboard, select the subject, and scan the teacher's QR code.
